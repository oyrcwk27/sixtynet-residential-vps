## 机房 IP 和家宽 IP 到底差在哪

差别在 IP 的归属记录上，不在速度上。

普通 VPS 分到的是数据中心 IP，查 WHOIS 显示归属某个机房或云服务商，整段地址上跑的全是服务器。住宅 IP 归属的是 ISP 分配给家庭用户的地址段，查出来是 Comcast、Cox、Wave 这类运营商。平台做风控时判断的第一层就是这条归属记录，第二层是这段 IP 上近期发生过什么。

SixtyNet 默认给的是单 ISP 住宅 IP，加 $5/月可以换成双 ISP：同一个 IP 在数据库里同时登记在两个运营商名下，属性更接近真实的家庭宽带出口。测评站 ipinfo 的数据库把这批地址判为双 ISP 属性，多个数据库给出的结论是原生美国 IP、家宽属性。这类判断只能说明 IP 归属层面的情况，跟账号能不能活下来是两件事。

## 三类家宽产品，SixtyNet 属于哪一种

市面上被统称为“美国家宽”的东西，实际有三种形态，独占性和价格差得很远。

**双 ISP 住宅 VPS**：就是 SixtyNet 这种。机房里的机器，配一段登记为住宅 ISP 的 IP，IP 归属干净但硬件仍在数据中心。优点是开通快、带宽大、可按月付；缺点是 IP 再干净也不是真的从民宅拉出来的线。适合 TikTok 账号、跨境电商店铺、流媒体这类主要看 IP 归属的场景。

**静态家宽 VDS**：硬件托管在美国真实民房里，向当地运营商申请光纤宽带。IP 稀缺，能过一些对“机房”极度敏感的验证。价格通常是前者的好几倍，且多为非大陆直连优化线路，国内远程连接要自备中转。**SixtyNet 官网目前没有核验到这一类产品**，如果你的业务必须用真民宅 IP，得另找商家。

**NAT 共享家宽**：一台机器上多个用户共用同一个出口 IP，价格最低。同一个 IP 上别人的行为会算到你头上，做账号的人基本不该碰。SixtyNet 也没有核验到这一类。

一句话的判断规则：不确定就选双 ISP 住宅 VPS；明确知道自己在做银行、运营商类高门槛验证，才需要去找静态家宽 VDS。

## 上手前要知道的三个技术限制

**80 和 443 端口是关的**。官网写明是 IP 风控原因。不要想着拿住宅 IP 机器去搭站、做落地页、跑 Web 服务，直接连不上。要用只能走非标准端口。

**默认屏蔽 PING，也不支持 IPv6**。测评记录里提到官方屏蔽了 ICMP，还屏蔽了 80/443，所以用 ping 测延迟会全部超时，这不代表机器挂了。IPv6 也没有。排查连通性要用 tcping 或直接测业务端口。

**部分系列首次登录会连不上**。官网对高安全系列写的是“拒绝所有外部探测与扫描，除非完成配置，只有白名单或端口转发过的设备能访问”。新机器开出来如果不先看面板里的说明，SSH 会一直超时。另外新开实例的 SSH 端口不一定是 22，具体端口在面板里看。

线路方面，第三方测评记录的去程是电信走 CN2 直连洛杉矶、联通和移动直连洛杉矶节点；回程电信和移动走 CN2，联通走 AS10099 + AS9929。硬件是 AMD EPYC 7002 系列，测评时 I/O 约 188MB/s，属于被限制过的水平，跑数据库密集型业务会吃力，跑浏览器环境和常规脚本够用。
